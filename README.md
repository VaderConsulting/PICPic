# PICPic

Freelance VB6 PICPic LED/bit editor (`PICPic.exe`, © 2004 D. Robinson) that toggles an 8-segment-style picture grid and shows the value as decimal, binary, and hex (red/black colour options). Open `PICPic.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe
